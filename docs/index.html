The skills

Six desks. Twenty skills.

How deep-dive works

A real process, not one giant prompt.

Pull the facts once

The data-analyst fetches XBRL financials, filing sections, the latest release and prices into a shared run folder.

Specialists in parallel

Earnings, forensics, valuation and industry analysts each write a sourced memo at the same time.

Bull vs. bear

Two agents steelman opposite cases from the memos, then rebut each other's strongest points.

PM verdict

The portfolio manager names the key debates, sets the view and kill criteria, and renders the report.

Why it's different

Skeptical by design.

Primary sources

Official SEC filings and XBRL, with true quarterly cash flows rebuilt from year-to-date reports. Free keys add consensus and prices.

Forensic instincts

Redlined risk factors, guidance credibility scores, call-evasiveness ratings, and Beneish, Altman, Piotroski and Sloan checks.

Reports worth sharing

Editorial HTML in light or dark with charts and a sources section on every page, plus Markdown for your notes.
