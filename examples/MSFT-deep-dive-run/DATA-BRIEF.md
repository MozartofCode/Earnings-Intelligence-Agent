## 8. Data-quality log
1. **Consensus/surprises unavailable** (no FMP/Finnhub/AV keys). Consensus is from one web search; Benzinga and Chartmill differ by ~$2B on revenue and $0.11 on EPS. The $96.0–97.1B guidance figure is from a search snippet, not the call transcript, so it is unverified.
2. **Next earnings date not confirmed:** calendar.json estimates 2027-01-27 (91-day cadence) [D11]; Chartmill cites 2027-01-26 [D12].
3. **Fiscal label seam in statements.json:** the quarterly `fy` field is the calendar year of the period end (e.g. 2025-09-30 is tagged 2025, but it is FY26 Q1). The labels in this brief are corrected by hand.
4. **Revenue reconciles:** XBRL FY27 Q1 $92,279M and FY26 $331,839M match the release income statements [D2][D4]. No revenue tag seam is visible.
5. **SG&A missing:** Microsoft tags S&M and G&A separately (FY26: $26.7B and $8.0B [D4]), so `sga` is null and Beneish SGAI defaulted to 1.0.
6. **Capex excludes finance leases:** capex = PaymentsToAcquirePropertyPlantAndEquipment only. Finance-lease-funded datacenter capacity is not in FCF, so FCF/FCF margin overstate cash after all capacity spend. The 10-Q cites "higher finance lease interest expense" [D1]. Pull the lease note from the full 10-Q.
7. D&A uses the rounded `Depreciation` tag, so EBITDA is approximate.
8. **GAAP EPS is distorted by investment marks:** OpenAI/Anthropic gains and losses run through other income. Use the non-GAAP or op-income lines for trend: FY26 Q2 EPS +59.8% and FY26 EPS +31.6% are inflated by these items.
9. FY27 segments differ from the 10-K. Recast history is only in the 10-Q/release.
10. Derived quarters (FY25 Q4, FY26 Q4) have null diluted shares. Quarterly DSO is not comparable to annual.
11. **Insiders** cover ~2.5 months, not 365 days (filing cap).
12. The SIC peer list is unusable as-is.
13. The quote is from an unofficial Yahoo endpoint. The 2026-11-04/05 8-Ks were not read.
